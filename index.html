Troque “Em Processamento” por “Processado com Sucesso” nos XMLs

Suba a pasta, os XMLs soltos ou o .zip/.rar. Todo arquivo com a tag Em Processamento é corrigido e volta em um ZIP com as pastas originais e o backup de cada arquivo alterado. Sem instalar nada, sem enviar o XML para servidor.

    Como funciona

    A mesma troca do Alterar-SituacaoAdn.ps1

    Uma única tag muda de valor; o resto do XML fica intacto. Pode rodar quantas vezes quiser — arquivo já corrigido não é tocado de novo.

    01

    O que muda

    <SituacaoAdn>Em Processamento</SituacaoAdn> → <SituacaoAdn>Processado com Sucesso</SituacaoAdn>

    Só essa tag é trocada. Os demais campos, valores, assinatura e a ordem das linhas do XML continuam exatamente como vieram da prefeitura.

    02

    Pode repetir sem medo

    XML que já está com Processado com Sucesso é ignorado, e XML sem a tag também: nada é reescrito à toa.

    Se rodar em cima de um lote já tratado, o resultado é o mesmo lote — só o relatório muda.

    03

    Backup e codificação

    O ZIP sai com os XMLs corrigidos nas mesmas pastas e uma pasta originais/ com o conteúdo de antes de cada arquivo alterado.

    A codificação é preservada (UTF-8 com ou sem BOM). Arquivo em outra codificação fica intacto e é listado como não alterado.
